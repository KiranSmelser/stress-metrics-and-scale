# stress-metrics-and-scale

Repository accompanying the paper, "How Scale Breaks “Normalized Stress” and KL
Divergence: Rethinking Quality Metrics." A web-based graphical interface
for exploring the behavior of normalized stress has also been made [available](https://kiransmelser.github.io/normalized-stress-is-not-normalized/).

## Contents

- `metrics.py`: Python module for computing various stress and KL divergence metrics between high-dimensional and low-dimensional data.
- `compute_metrics.py`: Script for computing stress metrics on dimensionality reduction (DR) results.
- `populate_datasets.py`: Script to load and save all datasets used in the experiment.
- `compute_embeddings.py`: Script for computing and saving embeddings using DR techniques for all datasets.
- `kl_statistics.ipynb`: Jupyter notebook for analyzing results of different KL divergence metrics on the considered datasets and embeddings.
- `stress_statistics.ipynb`: Jupyter notebook for analyzing results of different stress metrics on the considered datasets and embeddings.
- `viz.ipynb` and `plot_curves`: Jupyter notebook for creating the rest of the figures and tables seen in the paper.
- `figs/`: Folder containing the figures seen in the paper.

## Usage

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/username/repo-name.git
cd repo-name
python3.12 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### Scripts

Run the following scripts in the given order to generate all the information used to generate the experimental results.

1. `python populate_datasets.py`
    * The datasets used in the paper will be loaded and saved as .npy files in a new directory `datasets/`, while the class labels of the datasets will be stored as .npy files in `dataset_labels/`.

2. `python compute_embeddings.py`
    * Projections of different dimensionality reduction techniques will be computed for each dataset and stored in a new `embeddings/` directory.

3. `python compute_metrics.py`
    * Calculates different stress metric values for each projection in `embeddings/`, both without scaling and after scaling each projection 10 times, and stores in `out1x.json` and `out10x.json` respectively.
    * Creates a new directory `csv_files/`, and computes and stores different KL divergence metrics for each projection in that directory as JSON files.
    * Calculates coordinates required to plot KL divergence and normalized stress with respect to scale for each projection. These coordinates are stored as .npy arrays in a new directory `curve_coords/`.

4. `python ladder_experiment.py`
    * Calculates Normalized Stress and Scale Normalized Stress for each projection at different levels of perturbation, and stores results in `ladder_results.json`.

### Analysis and Visualization

After running the above scripts, tables and figures that appear in the paper can be generated by running the following Jupyter notebooks.

**stress_statistics.ipynb:**
* Analyzes the different stress metric values computed in `compute_metrics.py`.
* Generates Table 3 and Figure 7 from the paper.

**kl_statistics.ipynb**
* Analyzes the different KL divergence metric values computed in `compute_metrics.py`
* Generates Table 4 and Table 5 from the paper.

**viz.ipynb**
* Generates Figure 1 and Figure 2 from the paper and saves in `figs/` directory.

**plot_curves.ipynb**
* Generates Figure 3, Figure 4, Figures 8-13.
